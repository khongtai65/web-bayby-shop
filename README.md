## 🚀 Web Thực Tế (Với Database + PHP)

### Cách 1: Chạy trên Local (XAMPP)
1. Clone repo: `git clone https://github.com/khongtai65/web-bayby-shop.git`
2. Copy vào folder: `C:\xampp\htdocs\baby-shop\`
3. XAMPP → Start Apache + MySQL
4. Truy cập: `http://localhost/baby-shop/trang-chu.php`

**Tính năng:**
- ✅ Đăng nhập / Đăng ký
- ✅ Xem sản phẩm
- ✅ Thêm vào giỏ hàng
- ✅ Thanh toán
- ✅ Quản lý tài khoản
- ✅ Database MySQL (phpMyAdmin)

### Cách 2: Deploy lên Hosting (Infinityfree/000webhost)
1. Vào https://www.infinityfree.net hoặc https://www.000webhost.com
2. Tạo account miễn phí
3. Upload file lên bằng FTP
4. Create Database MySQL
5. Truy cập website trực tiếp
